BUILT FOR MANY MOVING PARTS

Keep the whole pool in sight.

PenguPool makes local agent work easier to follow while the agents keep running in their own sessions.

⌘

Switch without starting over

Open live tmux sessions from any editor window. Close the editor and come back to the same work.

⑂

See the relationships

Group sessions into a tree and follow a live map of parent, child, and cross-session messages.

◎

Give each session room

Start work in an isolated git worktree, describe each session's role, and track its current phase.

READY WHEN YOU ARE

Start on your machine.

One command installs the backend and the editor extension. PenguPool reads local session data; there is no hosted account to set up.

Requires Python 3.11+, Make, tmux 3.2+, VS Code or Cursor, and Claude Code and/or pi.

TERMINAL
curl -fsSL https://raw.githubusercontent.com/nduwork/pengutool/main/install.sh | bash
